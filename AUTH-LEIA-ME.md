# Acesso direto e sincronização opcional

O aplicativo abre diretamente, sem login nem cadastro. A escala, a biblioteca e a leitura de PDFs já importados continuam disponíveis neste aparelho, inclusive offline após preparar os recursos.

O botão Sincronizar é opcional. Para sincronização privada entre aparelhos, ele permite entrar com uma conta do aplicativo. Se não quiser usar conta, continue usando o app localmente e exporte os backups da escala e do estudo.

O banco mantém as políticas de acesso por conta. Os dados pessoais não ficam abertos para gravação pública. PDFs continuam importados em cada aparelho.

Depois de substituir os arquivos no GitHub, recarregue o site para receber a atualização. Uma instalação em cache pode precisar de uma segunda recarga. O arquivo auth.js das versões anteriores pode ser removido do repositório.
